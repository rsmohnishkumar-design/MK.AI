🔁 Oracle GoldenGate Replication Simulator

Change rows in the source database and watch Extract → Data Pump → Replicat copy them to the target in real time.

🟦 Source DB (ORCLSRC) · HR.EMP

🟩 Target DB (ORCLTGT) · HR.EMP

GGSCI (ogg-host) 1>
Try: INFO ALL · STOP REPLICAT REP1 (then change rows and see the lag grow) · START REPLICAT REP1 · STATS EXTRACT EXT1 · LAG REPLICAT REP1 · SEND EXTRACT EXT1, STATUS · HELP.
How it works: Extract reads committed changes from the source redo log and writes them to the local trail (./dirdat/lt). The Data Pump sends the trail across the network to the remote trail (./dirdat/rt). Replicat applies the changes to the target.
