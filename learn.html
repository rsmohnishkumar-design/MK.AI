    01

    What code is

    Code is a list of exact instructions for a computer. A computer is extremely fast, but it has no common sense. It does exactly what you write, in order, and nothing else.

    The simplest instruction inside Nova AI reads like this in plain English:

    When someone types hi, reply Hello!

    Coding is writing sentences like that in a language the computer understands, called a programming language. Nova AI is written in JavaScript, the language every web browser can run. Python, Java and C are other languages; they use the same ideas with different spelling.

    Three things every program does

    • Input: it receives something (your message).
    • Processing: it follows its instructions (checks if it's a greeting, does the maths).
    • Output: it shows a result (the reply bubble).

    05
    Loops: doing something many times
    
      
    A loop repeats a block of code. When you open an old chat, Nova AI loops through every saved message and draws each one on the screen. It doesn't matter if there are 3 messages or 100: the same few lines of code handle them all.
    
      
    
        
    Try it: how many messages?
    
        
        
    javascript
    for (let i = 1; i <= 4; i++) {
  drawMessage(i);   // runs once for each message
}
    
        
    
      
    
      
    Read the loop like this: start i at 1; keep going while i is at most N; after each round add 1 (i++).

    07
    Events: reacting to people
    
      
    Most of the time a web page is just waiting. An event is something that happens: a click, a key press, the page finishing loading. You tell the page "when this event happens, run this function". That's called an event listener.
    
      
    from Nova AI's js/app.js (simplified)
    sendBtn.addEventListener("click", () => {
  sendMessage();
});

question.addEventListener("keydown", (e) => {
  if (e.key === "Enter" && !e.shiftKey) sendMessage();   // Enter sends, Shift+Enter adds a line
});

    10
    Git and GitHub: how a change goes live
    
      
    Git saves snapshots of your code called commits. Every change has a history and can be undone. GitHub is the website that stores that history online.
    
      
    
        
      
    
      
    
        
    
          
    WordMeaning
    
          
            
    Repository (repo)The project folder with its whole history: rsmohnishkumar-design/MK.AI
    
            
    CommitOne saved snapshot, with a message saying what changed
    
            
    BranchA separate draft copy to work on without touching the live site
    
            
    Pull request (PR)A proposal to merge a branch into main, where it can be reviewed
    
            
    MergeAccepting the PR. GitHub Pages then rebuilds your site within a minute
    
              
        
    
      
    
      
    Every Nova AI feature you asked for went through this: the chat sync was PR #22, the new logo #23 and #24, creator mode #25, code boxes #26, typo-proof maths #27. That's why after each one you wait a minute and press Ctrl + Shift + R.
